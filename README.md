## Publish — correct repo required
Your existing repo `DennisMartinTO/DennisMartinTO` is your profile README repo — it is NOT a Pages site.
1. Create a NEW public repo named exactly `DennisMartinTO.github.io`
2. Upload ALL files in this folder to the root of `main` (drag-and-drop on GitHub works, keep `.nojekyll`)
3. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
4. Visit https://DennisMartinTO.github.io in 1–3 minutes

## Editing later
Edit any `.html` file directly on GitHub with the pencil icon — Pages rebuilds in ~1 minute. Keep navigation identical across pages.
